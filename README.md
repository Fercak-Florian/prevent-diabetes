# PreventDiabetes
This application has been developed to help doctors identify the patients most at risk of developing a form of diabetes  
This application is composed of 4 services.

## Prerequisite :

 - Java  17.0.16.1 (optional)
 - MySQL 8.4.11-0ubuntu0.26.04.1 (optional)
 - Docker 29.8.0
 - Docker Compose 5.5.1
 
## Installation :
 
#### Step 1 : download this project
 
#### Step 2 : dockerise the app
At the root's project, run the folowing command : docker compose up -d

#### Step 4 : Use your brower and go to the localhost:8085 address

#### Step 5 : use docker compose down -v command to stop and remove containers
